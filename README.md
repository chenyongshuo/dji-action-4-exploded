# OSMO ACTION 4 — Interactive 3D Teardown

DJI Osmo Action 4 的交互式 3D 结构拆解可视化页面。整机 9 大模块全部由代码程序化建模
（Three.js 几何体 + Canvas 程序纹理），**不依赖任何外部 3D 模型文件 / 图片 / 字体 / CDN**。

## 运行

直接双击打开 `index.html` 即可（经典 script 标签 + 本地 `vendor/three.min.js`，`file://` 下可正常工作）。
如需通过服务器访问：

```bash
python -m http.server 8765 --directory .
# 浏览器打开 http://127.0.0.1:8765/index.html
```

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面骨架：HUD 框架、部件清单、详情检查器、标注层、操作坞、操作指南弹窗 |
| `styles.css` | 深色科技风视觉系统（极光背景、网格、扫描线、面板、标注卡片、响应式） |
| `app.js` | 核心：程序化建模、拆解动画、轨道控制、射线拾取、发光高亮、标注投影、面板联动 |
| `vendor/three.min.js` | Three.js r159（UMD 本地副本，离线可用） |
| `qa/*.png` | 无头浏览器实测截图（指南弹窗 / 装配态 / 拆解态 / 选中态） |

## 交互一览

- **旋转 / 缩放 / 平移视角**：拖拽环绕、滚轮（或双指捏合）缩放，带阻尼惯性
- **点击部件拆解**：点击 3D 模型任意部件、左侧清单条目或场景标注卡，触发分层拆解动画并高亮该模块
- **一键拆解 / 组装**：底部橙色按钮，或快捷键 `SPACE`；`EXPLODE SEQUENCE` 滑杆可逐帧 scrub 拆解进度
- **部件详情**：右侧检查器显示分类、装配编号、6 项关键参数、结构说明、特性列表与装配关系
- **标注系统**：拆解后 9 张标注卡随 3D 锚点实时投影，SVG 引线连接，`L` 键开关
- **定位 / 取消选择**：检查器内「定位部件」将相机平滑推向所选模块；「取消选择」复位高亮
- **重置**：`R` 键或操作坞重置按钮，恢复默认机位与装配状态
- **数字键 `1–9`**：直接选择对应模块
- **操作指南**：启动时弹出，`?` 按钮可随时重开；移动端为抽屉式清单 / 详情面板

## 9 大模块（参数取自 DJI 官方技术页）

01 机身中框 · 02 超广角镜头组（155° f/2.8）· 03 影像传感器（1/1.3″ CMOS）·
04 前触控屏（1.4″ 320×320）· 05 后触控屏（2.25″ 360×640）· 06 主控电路板 ·
07 极端环境电池（1770 mAh）· 08 磁吸快拆底座 · 09 按键控制组

## 技术要点

- **程序化几何**：圆角挤出壳体、Lathe/球冠镜片、Canvas 生成的屏幕 UI / PCB 走线 / 电池标签 / 镜头刻字纹理
- **PBR 光照**：Canvas 梯度经 `PMREMGenerator` 生成环境反射；ACES Filmic 色调映射；软阴影接地
- **发光高亮**：选中/悬停模块时生成 BackSide 加色描边壳 + 同色点光源，拆解时中框半透明化显露内部
- **自研轨道控制器**：球坐标阻尼、双指捏合、点按/拖拽判别（<7px 且 <450ms 视为点击）
- **拆解编排**：每模块独立 delay/duration 的错峰缓动，滑杆 scrub 与按钮动画共用同一进度场
- **标注投影**：3D 锚点 → NDC → 屏幕坐标，卡片在面板间安全区内钳制，引线为折线 SVG
